# Exact V4 migration fixture

This directory contains an immutable SwiftData store generated by the exact
OpenASO V4 source snapshot:

- commit: `77bc4c39735f8d68376347f671fd4c8ac34d684c`
- tree: `f99c6e8349b253e8220b8dae9258059e3c8ab455`
- schema: `4.0.0`

The fixture seeds every one of the 21 V4 model types. Its base V1 graph uses
the established released-fixture sentinels, then adds fixed V2 refresh-attempt,
V3 status-event, and V4 difficulty/evidence sentinels. Estimated and unavailable
difficulty states are represented on independent query keys, with five valid
evidence rows across the two calculations.

Regenerate only when intentionally replacing this immutable fixture:

```sh
./script/generate_v4_migration_fixture.sh
```

The generator checks out the exact commit into a detached temporary worktree,
verifies its tree, applies the reviewed generator patch, and opens only a
scratch store with `OpenASOSchemaV4`. It never opens the application's live
persistent store. The script refuses to overwrite an existing manifest or
store artifact; remove those files explicitly only as part of a reviewed
fixture replacement.
