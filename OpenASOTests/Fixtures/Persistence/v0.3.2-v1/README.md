# OpenASO v0.3.2 V1 persistence fixture

This directory is reserved for an immutable SwiftData store generated by the released `v0.3.2` source at commit `7a2c3752fa895ad820663a5b4baeaf926f0b65f9`.

`OpenASOSchemaV1` and its model definitions are frozen with this fixture. Future schema work must append a new version rather than editing V1 in place.

Generate it from the repository root with:

```sh
./script/generate_v032_migration_fixture.sh
```

The generator uses a detached disposable worktree and an isolated temporary store path. It never opens or writes OpenASO’s Application Support database.

The fixture seeds exactly one deterministic row for every entity in the released V1 schema, including representative optional scalar values and the folder, app, metadata, rating, review, keyword, crawl, and ranking relationship graphs.

Generated and reviewed files:

- `default.store`
- `default.store-wal` and `default.store-shm`, only when the released runtime leaves them alongside the store
- `manifest.json`, containing the exact release tag/commit, schema version, byte counts, and SHA-256 checksums for every store artifact

Do not hand-edit or regenerate these files from current source. A fixture is useful only when its bytes were produced by the named released source revision.
